MilkDrop macOS

This package includes the app, 9,795 Cream of the Crop presets, and the shared MilkDrop texture pack. No downloads, Nix, or Xcode are needed to run it.

Install

Requires an Apple Silicon Mac (M1 or newer) running macOS 14.2 or newer. Older macOS versions than the developer's macOS 26 have not yet been tested.

Use either the installer or the ZIP, not both. The installer puts MilkDropMac.app in Applications and may ask for an administrator password. Alternatively, unzip the ZIP and drag the app into Applications. All presets and textures are inside the app.

This is a development build without Apple notarization. If macOS blocks the app or installer, first try opening it, then use System Settings → Privacy & Security → Open Anyway. Do not disable Gatekeeper globally. Apple's opening instructions.

Play

Open MilkDropMac from Applications. Presets shuffle every 30 seconds. Click System Audio and allow audio-recording permission to visualize music playing on your Mac. Demo mode supplies synthetic input; it doesn't play sound.

⌘B opens the searchable preset browser; ⌘N shuffles immediately. Use the interval control to change the timing. Previously installed personal collections take priority; a fresh Mac automatically uses the bundled collection.
